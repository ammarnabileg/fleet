# BrilliantTech UI — قالب نظام إدارة الأسطول

قالب واجهات كامل (HTML + CSS + JavaScript) لنفس تصميم العرض التقديمي:
**لوحة الإدارة + تطبيق السائق + بوابة مراكز الصيانة + صفحة الدخول + مكتبة المكونات**،
بكل الشاشات والنوافذ المنبثقة، بالعربية (RTL)، مع وضع داكن ودعم للجوال.

- بدون أي مكتبة خارجية وبدون build: افتح `index.html` في المتصفح مباشرة.
- الخط والأيقونات محلية داخل المجلد، فالقالب يعمل بدون إنترنت.
- البيانات تجريبية لكنها متسقة بين كل الشاشات، ومكانها ملف واحد: `assets/js/data.js`.

---

## 1) التشغيل

| الطريقة | الأمر |
|---|---|
| الأسهل | افتح `index.html` بالضغط المزدوج |
| بسيرفر محلي (مستحسن للتطوير) | `python3 -m http.server 8080` ثم افتح `http://localhost:8080` |

المتصفحات المدعومة: Chrome وEdge وSafari وFirefox (الإصدارات الحديثة).

### بوابة مراكز الصيانة (`portal.html`)
السيارات المحالة ومراحلها · تسجيل الاستلام بالصور · تحديث الحالة · عرض السعر ببنود · الفاتورة ومقارنتها بالعرض · تقدير تلفيات الحوادث · مستخدمو المركز.
للتجربة: قائمة المستخدم ← «عرض كمركز آخر» (مركز الغانم لديه حادث بانتظار التقدير).

### تطبيق السائق (`driver.html`)
الدخول برمز OTP وربط الهاتف · الرئيسية · بدء اليوم (صورة العداد + الرقم) · التقرير اليومي · الكاش والحركات · الإيصالات وتأكيد الاستلام · الصيانة · الإبلاغ عن حادث · حسابي والمستندات والراتب.
أزرار «انتقل إلى» في الجانب تفتح أي شاشة مباشرة (`driver.html#login` يبدأ من الدخول).

## 4) النوافذ المنبثقة (كلها في `ui.js`)

| النوع | الاستدعاء | مثال في القالب |
|---|---|---|
| Modal | `BT.modal.open({...})` | إضافة سيارة، مراجعة التقرير، اعتماد العرض |
| Drawer (لوحة جانبية) | `BT.drawer.open({...})` | بطاقة السيارة، دفتر السائق، ملف الموظف |
| Bottom sheet | `BT.sheet.open({...})` | كل نوافذ تطبيق السائق |
| Confirm | `BT.confirm({...}).then(r => r.ok)` | إلغاء إيصال (بكتابة الرقم)، إقفال الرواتب، إيقاف سيارة |
| Toast | `BT.toast('نص', {type, sub, action})` | بعد كل حفظ |
| قائمة منسدلة | `BT.menu(el, items)` | قائمة المستخدم، إجراءات الصف |
| Popover | `BT.popover(el, html)` | الإشعارات |
| Tooltip | `data-tip="نص"` في HTML | أزرار الأيقونات |
| Lightbox | `BT.lightbox([{src|html, caption}], i)` | صور العداد، لقطة الشاشة، صور الحادث، المستندات |
| البحث السريع | `Ctrl + K` أو `BT.cmdk({source})` | البحث عن سيارة/سائق/صفحة/إجراء |
| طباعة | `BT.print(html)` | الإيصال وقسيمة الراتب |

خيارات Modal/Drawer/Sheet المشتركة:

```js
BT.modal.open({
  title: 'عنوان', subtitle: 'وصف', icon: 'car', iconTone: 'danger|warn|success',
  size: 'sm | lg | xl',          // modal فقط (drawer: 'lg')
  body: BT.h`<div>…</div>`,
  form: true,                    // يغلّف المحتوى في <form> ويتحقق تلقائياً عند الحفظ
  buttons: [
    { label: 'إلغاء', cls: 'btn-ghost' },
    { label: 'حفظ', cls: 'btn-primary', icon: 'check', submit: true }
  ],
  footNote: 'ملاحظة في التذييل',
  onSubmit: function (values, api) { /* return false = تبقى مفتوحة · يمكن إرجاع Promise */ },
  onClose: function () {}
});
```

كلها: تُغلق بـ Esc أو بالضغط خارجها، تحبس التركيز داخلها (Tab)، تعيد التركيز للزر الذي فتحها، وتتحول لـ Bottom sheet على الجوال.

## 5) كيف تعدّل وتضيف

**تغيير الألوان أو الهوية:** `assets/css/tokens.css` فقط (القسم الأول للوضع الفاتح، والثاني للداكن).
الاسم والعميل والقواعد (حد الكاش، حد الاعتماد…) في `BT.config` أول `core.js`.

**صفحة جديدة في لوحة الإدارة:**
1. أضف عنصراً في `A.NAV` داخل `assets/js/admin.js`.
2. اكتب الصفحة في أي ملف داخل `pages/`:
```js
BT.pages['fuel'] = function (params, query) {
  A.setTitle('الوقود');
  BT.render(A.view(), BT.h`${A.head('الوقود', 'وصف')}<div class="card">…</div>`);
};
```
3. الرابط: `admin.html#/fuel` (والمعاملات: `BT.pages['fuel/:id']`).

**زر ينفّذ إجراء:** `<button data-action="my-action" data-arg="123">` ثم `BT.actions['my-action'] = function (arg, el) {…}`.

**أيقونة جديدة:** اكتب `BT.icon('fuel')` أو `<i data-icon="fuel"></i>` (الأسماء من https://lucide.dev/icons) ثم:
```
npm i lucide-static
python3 tools/build_icons.py --icons node_modules/lucide-static/icons
```

**HTML آمن:** استخدم دائماً `` BT.h`…${value}…` `` لأنها تهرّب القيم تلقائياً (حماية من XSS)، و`BT.raw(html)` فقط لـ HTML موثوق.

**الأرقام والتواريخ داخل النص العربي:** `BT.fmt.date()` و`BT.fmt.kwd()` و`<span class="num">`، فلا يظهر التاريخ مقلوباً (2026-11-24 بدل 24-11-2026).

## 6) الربط بالنظام الفعلي (للمطورين)

1. **البيانات:** استبدل `data.js` بطبقة API ترجع نفس شكل الكائنات (`vehicles`, `employees`, `reports`, `receipts`, `jobs`, `accidents`…). الصفحات تقرأ من `BT.data` فقط.
2. **الحفظ:** كل `onSubmit` حالياً يعدّل البيانات في الذاكرة. استبدله بـ `fetch` وأرجع Promise، فيظهر التحميل على الزر تلقائياً.
3. **رفع الملفات:** قيم حقول الملفات تصل كـ `File[]` في `values` ← ارفعها بـ `FormData`.
4. **الخريطة:** `BT.kuwaitMap` رسم توضيحي فقط، ويُستبدل بـ Google Maps أو Mapbox أو Leaflet بنفس فكرة الدبابيس والمسار.
5. **الدخول و OTP:** الواجهة فقط؛ التحقق الفعلي والجلسات من الخادم.
6. **الصلاحيات:** المصفوفة في الإعدادات واجهة، والتطبيق الفعلي للصلاحيات يكون في الخادم وليس في الواجهة.

## 7) حدود القالب (مهم)

- **بيانات تجريبية:** كل الأسماء والأرقام وهمية. أي تعديل يُفقد عند تحديث الصفحة.
- **«الكاميرا فقط»:** الخاصية `capture="environment"` تفتح الكاميرا مباشرة على معظم هواتف أندرويد وiPhone، لكنها **ليست ضماناً**؛ بعض المتصفحات تسمح بالمعرض. منع المعرض فعلياً يتم في تطبيق أندرويد الأصلي (CameraX) وليس في HTML.
- **تطبيق السائق هنا نموذج HTML** لنفس الشاشات. التطبيق الفعلي أندرويد أصلي، والتتبع في الخلفية طوال اليوم لا يمكن تنفيذه بصفحة ويب.
- **الإنجليزية:** زر اللغة موجود لكن القالب بالعربية فقط.
- **لا مدفوعات داخل النظام:** «تسجيل كمدفوع» في المالية تسجيل محاسبي فقط، والدفع يتم خارج النظام.
- **البريد الإلكتروني** يظهر كخدمة إضافية مدفوعة (غير مفعّلة)، **وتطبيق iPhone** عند الطلب (250 د.ك سنوياً + 100 دولار App Store)، حسب العقد.
- إمكانية الوصول: فيها الأساسيات (تركيز الكيبورد، aria، التباين، بدائل جدولية للرسوم) لكنها لم تُدقَّق تدقيقاً رسمياً.
